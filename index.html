轻译 LiteTranslate 隐私政策

生效日期：2026 年 11 月 5 日

轻译（以下称“本扩展”）是一款浏览器翻译扩展。我们非常重视你的隐私：本扩展没有自己的服务器，不收集、不出售、不分享任何个人信息，也不包含任何统计或广告代码。

1. 本扩展处理哪些数据

数据用途发送给谁
你选中或输入的文字、需要翻译的网页文字完成翻译仅发送给你当前选择的翻译服务：谷歌翻译（默认）、OpenAI 或 Anthropic，或你在设置中填写的接口地址
扩展设置（目标语言、翻译引擎、不自动翻译的网站列表等）记住你的偏好只保存在你的浏览器本地，不会上传
你填写的 API Key调用你自己的 OpenAI / Anthropic 账户只保存在你的浏览器本地，只随翻译请求发送给对应的接口

2. 网页内容的访问

为了实现划词翻译、整页翻译和外语网页自动翻译，本扩展需要读取你正在浏览的网页内容。网页文字只会在翻译时发送给上述翻译服务，不会被本扩展存储或用于其他目的。你可以随时在设置中关闭“自动翻译外语网页”，或将某个网站加入“不自动翻译的网站”。

3. 第三方服务

翻译由第三方服务完成，它们对数据的处理适用各自的隐私政策：

  • 谷歌翻译：https://policies.google.com/privacy
  • OpenAI（仅在你选择 ChatGPT 并填写 API Key 时使用）：https://openai.com/policies/privacy-policy
  • Anthropic（仅在你选择 Claude 并填写 API Key 时使用）：https://www.anthropic.com/legal/privacy

4. 数据删除

卸载本扩展会删除它保存在浏览器中的全部设置和 API Key。

LiteTranslate Privacy Policy

Effective date: November 4, 2026

LiteTranslate (“the extension”) is a browser translation extension. The extension has no servers of its own. It does not collect, sell, or share any personal information, and it contains no analytics or advertising code.

1. Data the extension handles

DataPurposeSent to
Text you select or type, and page text to be translatedTranslationOnly the translation service you choose: Google Translate (default), OpenAI, Anthropic, or the API endpoint you enter in settings
Extension settings (target language, engine, sites excluded from auto-translation, etc.)Remember your preferencesStored locally in your browser only; never uploaded
API keys you enterCall your own OpenAI / Anthropic accountStored locally in your browser; sent only to the matching API with translation requests

2. Access to page content

To provide selection translation, full-page translation and automatic translation of foreign-language pages, the extension reads the content of the page you are viewing. Page text is sent only to the translation service above when a translation is performed, and is not stored or used for any other purpose. You can turn off automatic translation or exclude specific sites at any time in settings.

3. Third-party services

Translations are performed by third-party services, whose own privacy policies apply:

  • Google Translate: https://policies.google.com/privacy
  • OpenAI (only if you choose ChatGPT and provide an API key): https://openai.com/policies/privacy-policy
  • Anthropic (only if you choose Claude and provide an API key): https://www.anthropic.com/legal/privacy

4. Data deletion

Uninstalling the extension removes all settings and API keys it stored in your browser.
